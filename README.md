# Automated Data Cleaning and Profiling Tool

## Overview

This project is a modular Python-based data cleaning and profiling solution designed to automate common data preprocessing tasks. It enables users to load datasets, assess data quality, clean inconsistencies, and generate profiling reports for exploratory analysis.

## Features

* Automated dataset loading
* Missing value detection
* Duplicate record identification
* Data quality assessment
* Dataset profiling
* Report generation
* Modular architecture for scalability

## Technologies Used

* Python
* Pandas
* NumPy
* ydata-profiling
* Jupyter Notebook

## Modules

### file_loader.py

Responsible for loading and validating input datasets.

### cleaning_engine.py

Handles data cleaning operations such as missing value treatment, duplicate removal, and data standardization.

### data_profiler.py

Generates detailed data profiling reports for exploratory analysis and data quality assessment.

### app.py

Main execution file that integrates all modules and runs the complete workflow.
